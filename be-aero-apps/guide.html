Guide and help

Set up BE-Aero, then get the most out of it.

Start with the setup planner: tick what you own and it writes your steps. Everything after it is reference you can search.

The public downloads currently serve Desktop 1.2.9 and Relay 1.0.2. Features marked 1.3.0 here (the Android suite, realtime sync, the VPN hub, BE-Aero Link) are built and not yet published.

Plan my setup

Tick everything you want to connect. The steps below rewrite themselves, in the order that works. Tick a step when you finish it; this browser remembers your place.

    Install and update

    Install on Windows

    In PowerShell, on Windows 10 or 11. This downloads the installer (about 120 MB) from the latest published release and runs it.

    curl.exe -fL --progress-bar -o BE-Aero-Desktop-Setup.exe https://github.com/BE-AI-Research/be-aero-desktop/releases/latest/download/BE-Aero-Desktop-Setup.exe
.\BE-Aero-Desktop-Setup.exe

    The installer asks for administrator permission. If nothing seems to happen, look for the Windows permission prompt behind your other windows.

    No install? The portable build is a single file you just run. It cannot update itself, so it tells you when a new release is out.

    curl.exe -fL --progress-bar -o BE-Aero-Desktop-Portable.exe https://github.com/BE-AI-Research/be-aero-desktop/releases/latest/download/BE-Aero-Desktop-Portable.exe

    Install on Linux

    One command. It downloads the latest release (about 120 MB) and installs to /opt with a menu entry and a be-aero-desktop command. Run it again to update.

    curl -fsSL https://github.com/BE-AI-Research/be-aero-desktop/releases/latest/download/install-linux.sh | sudo bash

    BE-Aero runs on X11 and XWayland, not native Wayland. On GNOME, turn on the dock helper once so the dock can see your windows, then log out and back in:

    gnome-extensions enable be-aero-dock@be-ai-research

    Useful extras: playerctl for Now Playing, wmctrl and xprop for the dock on X11 sessions. To remove BE-Aero: sudo bash install-linux.sh --uninstall.

    Updates

    BE-Aero checks for releases a few times a day, and on demand from Settings or the tray.

    • Windows, installed: updates itself in the background, after checking the download against the release's published hash.
    • Linux: turn on Install updates automatically. It asks for your password once, then installs when the computer has been idle for 5 minutes. Install now skips the wait.
    • Portable: shows a notification that opens the release page.

    Check a download

    Every release lists a checksum for each file in SHA256SUMS.txt.

    Windows SmartScreen may warn on first run because the builds are not code-signed yet. Choose More info, then Run anyway, if you trust the source.

    Desktop basics

    BE-Aero sits on your desktop. The empty space between widgets lets clicks through to whatever is behind.

    Docked or free-form

    Docked keeps widgets in a strip on the left or right edge of a monitor you choose. Free-form turns every monitor into one canvas: drag widgets anywhere, between displays, with optional snap to grid.

    Sizes and positions are remembered separately for each mode. Reset widget sizes & positions in Settings or the tray clears them.

    Move, resize, lock, minimize

    • Drag the corner grip to resize. Double-click it for the default size.
    • Right-click a widget and choose Lock in place to pin it. The global lock in Settings locks them all.
    • Hover a widget for its minimize button. It parks in the dock, and a click brings it back.

    The dock

    Pinned apps, every open app with its real icon, a running dot and a window count. Click to focus, click again to cycle that app's windows, right-click to manage them.

    At the end of the dock: the widget tray, the notification bell, settings, the system's own settings, the Recycle Bin, a UAC shield on Windows and the power button. In 1.3.0 a network tile shows the connection, live speed and Wi-Fi networks to join.

    Tray icon and toolbar

    Click the tray icon to show or hide BE-Aero. Right-click it for widgets, position, always on top, launch at startup and quit. Hover the top of the widget strip for the toolbar with the settings gear.

    Notification center

    The bell collects notifications from your apps, web widgets, the assistant, downloads and updates. They are grouped by app and, for chat apps, by conversation. Dismiss one message, a conversation or a whole app.

    Power menu

    Lock, Switch user, Log off, Sleep, Hibernate, Restart and Shut down. The last ones ask first. Hibernate is greyed out, with how to turn it on, when Windows has it off.

    ShortcutWhat it does
    Alt + SpaceOpen search from anywhere. If another app owns it, BE-Aero falls back to Ctrl+Space, then Ctrl+Alt+Space, then Win+Shift+Space. The search bar shows which one is active.
    Ctrl + Alt + WShow or hide the widgets
    Ctrl + Alt + DBring the dock above whatever is on screen, a full-screen game included. Press again, or pick an app, to send it back.
    Ctrl + LFile browser: type a path in the address bar
    Shift + dragFile browser: move instead of copy

    Search

    One bar for apps, Store apps and web apps, system settings, files in Desktop, Documents, Downloads, Pictures, Music and Videos, and results from your other devices.

    How matching works

    It tolerates typos (calculater), acronyms (vsc finds Visual Studio Code) and partial words. Things you open often rank higher. The index rebuilds every 30 minutes.

    Keys: ↑ ↓ to move, Enter to open, Ctrl+Enter to show in folder, Tab to accept the suggestion, Esc to close.

    Change the hotkey

    Settings > Search & general. Click the box and press any combination. If another app already owns it, BE-Aero says so and uses one that is free.

    cmd> ipconfigRun a command in a terminal that stays open. cmd> alone opens a terminal.
    aero:reindexRebuild the search index now

    Widgets and themes

    Every widget can be switched on or off from the tray or the widget tray in the dock.

    WidgetWhat to know
    ChronometerSeven faces: analog, classic, minimal, hybrid, digital, flip clock and rings
    WeatherLive conditions from Open-Meteo, no key needed. Make it taller for the 7-day forecast. Pick any city in Settings.
    System telemetryCPU, memory, disk, network and battery in five styles: rings, arcs, bars, graphs or chips, with a per-core heatmap
    Now PlayingWhatever is playing on this device, or on any connected device from the drop-down
    SoundOutput device, master volume, a slider per app, and Bluetooth devices. All devices shows each device's volume side by side.
    ScratchpadSeveral notes, saved automatically. + starts one, ‹ › move between them. Save writes a .md or .txt file.
    File browserList, tile and tree views. See Files and File Pool.
    AI chatSee The assistant

    Web frames

    Also called web widgets. Turn any page into a widget: tray > Create widget from web address. Good for a Grafana board, a Home Assistant dashboard or any device on your network.

    • Each one is a full, isolated browser view, so sites that refuse to be embedded still work and your logins persist.
    • Hover for reload and zoom, 33% to 200%.
    • A self-signed certificate shows a warning page. Only Proceed trusts that exact certificate for that address.
    • A site in a web frame cannot use your camera, microphone or location.
    • 1.3.0: WebGPU. Pages get hardware graphics, with a setting of Automatic, On or Off and a per-frame Fast GPU option for machines with two graphics cards. On Linux it is opt-in and experimental.

    AI widgets

    Ask the assistant to "make me a widget that…" and it builds one: a countdown, a to-do list, a converter, a dashboard.

    • Each widget is a folder under AI Widgets in your AI Folder. Edit index.html and it reloads.
    • A widget that needs a website asks once. Review or revoke approvals in Settings > AI assistant.
    • Any .html file can become a widget: right-click it in the file browser > Create widget.

    Themes

    Nine presets: Aero, Midnight, Frosted glass, Emerald, Sunset, Rose quartz, Amber terminal, Graphite and Clear. Adjust any of them (glass tint and strength, accent, text colour, edge, sheen, corner radius) and reset in one click. With theme sync on, your other computers follow.

    You can try all nine on this site. Your choice carries over to this guide.

    The assistant

    A chat widget that can operate the desktop: change settings, launch and manage apps, read and write notes, search, browse the web and work inside pages.

    Choose where it runs

    Settings > AI assistant. Pick a provider, add a key if it needs one, then Fetch models.

    • On this computer or your network: Ollama, LM Studio, llama.cpp or any OpenAI-compatible server. For Ollama (LAN server), type just the address, for example 192.168.1.20.
    • Online: Anthropic, OpenAI, Google Gemini, OpenRouter, Groq, Mistral, DeepSeek, xAI, Together AI, Fireworks and Perplexity. Get a key opens the provider's key page, and saving a key checks it.

    Keys are stored encrypted with the operating system's keychain, one per provider, and never reach the page. With an online provider, your prompts go to that provider. With your own server they stay on your machines.

    Permissions

    Reading never asks. Anything that changes something (settings, launching, closing windows, working in a page) follows your choice: ask each time, always allow or never.

    The assistant also asks before reading your clipboard or saving a memory, and it cannot give a scheduled task full permission. Only you can, in Settings.

    Browsing

    Pages open in your own browser. To click or type in a page, the assistant uses a separate browser profile (sign in to sites there once), and by default it asks you first.

    Choose the browser in Settings > AI assistant: Chrome, Edge, Brave, Chromium or Firefox. Firefox can open pages, but clicking and typing need a Chromium browser.

    Working in the chat

    • Tabs: several conversations at once, and a searchable conversation list. A dot marks new activity.
    • Queue: keep typing while it works. Messages run in order. Stop clears the queue.
    • Attach images, PDFs and text or code files.
    • Voice: dictate with the microphone button and have replies read aloud, with Play, Pause and Stop. Speech recognition runs on your machine.
    • Pin the widget to keep it above other windows during a long task.

    Context and step limits

    The status line shows how full the context is. When it fills, old tool output is trimmed, then older conversation is summarised. Your saved history is never deleted. Type /compact to do it on demand.

    Settings sets how many tool steps one message may take. At the limit the assistant answers from what it has found.

    Memory

    Lasting facts about you and your work carry across conversations. Review, add or delete them in Settings, or switch memory off.

    Optional: a BE Brain server adds long-term memory and picture memory, with an offline queue for when it is out of reach.

    Its own tools

    The assistant can write tools for things you do often and reuse them. They live under AI Tools in the AI Folder.

    • Sandbox tools run isolated: no files, no network, stopped after 30 seconds.
    • Script tools (PowerShell, bash, Python) run only after you approve that exact code. Any edit needs approval again.

    Assistants on different devices

    With AI requests allowed between two devices, one assistant can ask the other a question or send it a task. A question waits up to 5 minutes, and a late answer still arrives.

    Work sent from another device runs in its own conversation and cannot drive your windows, mouse or keyboard unless you allow it.

    Turn it off

    One toggle in the tray or Settings disables the AI. The widget, the search row and every AI call go away.

    Scheduled tasks

    Prompts that run on their own, from the clock tab in the chat. Each task writes into its own conversation and reports to the notification center. You can also just ask: "every morning at 9, summarise my scratchpad".

    Type in "When"Runs
    daily 09:00Every day at 9:00
    weekdays 08:30Monday to Friday at 8:30
    mon,thu 14:30Mondays and Thursdays at 14:30
    every 2hEvery two hours. The shortest repeat is 5 minutes.
    in 20mOnce, 20 minutes from now
    at 2026-12-01 09:00Once, at that time
    every weekday at 8:30 amPlain wording works too, and so does a cron line. The form previews the next three run times.

    What a task may do

    Each task has its own policy for unattended runs: autonomous, read-only, or as in Settings. Where Settings says "ask", a task runs read-only, because nobody is there to answer.

    When things go wrong

    • A time missed while the computer slept runs once when you are back.
    • A run stops after 30 minutes by default.
    • After 3 failures in a row a task pauses itself and tells you.

    A different model for tasks

    Settings > AI assistant has Provider for scheduled tasks and Model for scheduled tasks, and a task can pick its own. Chat can use a model on this PC while tasks use a shared server.

    Connected devices

    Device connections are off until you turn them on in Settings > Devices. Everything travels directly between your devices, or sealed through your relay. There is no account and no BE-Aero cloud.

    Pair two devices

    1. On one device, show a pairing code. It is 6 digits, valid for 5 minutes and 5 tries.
    2. Enter it on the other. Devices on the same network find each other. Otherwise choose Pair by address.
    3. Choose what the new device may do.

    Unpair, rename, move

    Removing a device removes it on both sides, at once if it is connected or the next time it connects. Pairing again replaces any old pairing.

    If a device or relay gets a new IP address, Settings > Devices > Address… tells BE-Aero where it moved.

    PermissionLets the other device
    Browse filesSee the folders you share with it. Only the File Pool until you share more.
    File PoolKeep the File Pool in sync with this device
    Synced stateExchange theme, notes, pins, conversations, tasks and shared web widgets
    AI requestsHave its assistant send yours questions and tasks
    NotificationsSend notifications here
    ClipboardSend its clipboard here. Only ever sent by hand.
    Media & volumeSee and control what plays here, and change the volume

    Keep the same on my devices

    Settings > Devices. Only Theme starts on. Turn on scratchpad notes, pinned apps (between devices with the same operating system), AI conversations, scheduled tasks and clipboard when you want them.

    • The newest change to each item wins, and deletes travel too.
    • Conversations split into Synced to your devices and Local. Right-click a chat tab to move it.
    • A task runs only on the device that created it. The others show "runs on" that device.
    • Window size, position and zoom never sync.

    Send to device

    Clipboard: tray > Send clipboard to a device sends text or an image. Turn on Clipboard in Settings > Devices first.

    Web widgets: right-click one > Send to a device, or Share with all my devices.

    Devices that are offline but reachable through a relay are listed too.

    Realtime sync: control either device from the other (1.3.0)

    Pick a device under any chat and both show the same conversation as it happens. Ask on either, the answer streams on both, and either carries on. The device you asked on runs the model. The other only mirrors.

    In a synced conversation each assistant can use the other device's tools. The device that runs a tool decides whether its user is asked first.

    A phone needs a direct connection or the VPN for this. It does not work through the relay mailbox.

    Sharing one AI server

    When several devices use the same Ollama server they coordinate. If your model is not loaded but one your other device uses is, this turn uses that one and says so. A model one device is using is never unloaded to make room.

    Files and File Pool

    File browser

    Places for your home folders, drives, the File Pool, the AI Folder, network drives, your other devices and your relay. List, tile or tree view, as many windows as you like.

    • A click opens. Ctrl or Shift-click selects, and so does dragging a box.
    • Copies and moves run as jobs with progress, Pause, Resume and Stop. A stopped copy leaves no half-written file.
    • Deleting sends to the Recycle Bin or Trash.
    • Network drives: connect to \\server\share or smb://server/share. BE-Aero never stores the password.

    File Pool

    One folder, ~/BE-Aero Pool, kept the same on every paired device that allows it. New files, edits, renames and deletes travel both ways.

    • A delete on one device moves the file to the Recycle Bin on the others.
    • If two devices edit the same file at once, the other version is kept beside it as a conflict copy.
    • Share my File Pool with my devices in the BE-Aero menu turns all of it off for this device.

    Share a folder with a device

    Right-click a folder and choose Shared index, then tick All my devices or individual ones. Ticked devices can search that folder and open its files. Folders on other devices are read-only: opening a file downloads it first.

    The AI Folder

    ~/BE-Aero AI by default. Files you attach in chat go to Uploads. The assistant can write files, but only inside this folder. What it makes is kept in AI Artifacts, AI Widgets and AI Tools.

    Relay server

    Optional. A small always-on server of your own, on a Linux box or VM, for when your devices are not online together or not on the same network. The relay cannot read what it carries, and it gets none of a device's permissions. The dashboard, VPN hub and gateway below are relay 1.2, a development build. The published relay is 1.0.2.

    Everyday commands

    CommandDoes
    sudo be-aero-relay pairPrint the address, port and a 6-digit code for pairing a device
    sudo be-aero-relay statusPaired devices, online or not, and what waits for each
    sudo be-aero-relay panelOpen the full-screen control panel. ? shows keys, q quits and the relay keeps running.
    sudo be-aero-relay tunnelSet up the VPN hub. Needed once.
    sudo be-aero-relay auto-update onInstall new releases daily, only when the published checksum matches
    be-aero-relay --versionThe version installed

    On Windows use be-aero-relay.exe pair. In Docker: docker exec be-aero-relay node relay.js pair.

    What it stores

    • Waiting messages for offline devices: state changes, AI requests and answers, clipboard and web-widget sends. Uncollected messages are deleted after 30 days.
    • Shared storage: a folder all your devices can open.
    • File Pool copy: kept current by whichever device is online.

    Messages and files together are capped at 2 GB by default. Change it in the panel's Settings.

    VPN hub: your LAN, anywhere

    Once a device joins the hub it reaches your other devices and your home network as if it were at home.

    The relay is a WireGuard hub for your devices. Computers and phones join it from their own settings. The tunnel carries your devices and the home network, not the rest of the internet. A phone can opt in to an exit node that sends all of its traffic through home. Forward UDP 51820 on your router.

    Windows uses WireGuard for Windows. Linux uses NetworkManager or wg-quick. On Android it is built in.

    Until it has been set up with root once, the hub waits in standby. Run sudo be-aero-relay tunnel, or open the panel with sudo and press t.

    Reaching it away from home

    Forward TCP 41811 on your router to the relay, or put the relay and your devices on the same VPN.

    Inference and memory through the relay

    List your inference servers in the relay's settings and your devices can use them from anywhere. The relay reaches only the servers you list.

    Set your BE Brain address and key and your devices' memory requests go through the relay to it. Create the key on the Brain with brainctl add <id> --relay.

    Device directory

    The relay introduces your online devices to each other so they connect directly, even through firewalls. From 1.3.0 you can pair a new device through the relay.

    BE-Aero Link

    A single executable for Linux or Windows that puts a machine without BE-Aero, such as a server or an inference box, on your VPN. It pairs with the relay by code, joins the hub and keeps the tunnel up as a service. Built, not yet published.

    Control panel tabs

    Overview (live gauges and traffic), Devices (u unpairs, p pairs), VPN, Services (c checks your Brain and inference servers), Settings (r restarts) and Log (/ filters).

    Android

    BE-Aero for Android is one install with three apps sharing one connection to your devices. It is a beta for Android 12 and later, installed from the APK. It is not in any app store and has not been published yet.

    BE-Aero Launcher

    Pages of apps, Aero widgets (at a glance, clock and weather, weather, media, AI, files) and any Android widget. Drag, resize and long-press for menus. A dock, and a drawer that follows the finger.

    Dual home screen: the launcher keeps two home screens, one for upright and one for on its side. Turn a phone or tablet and the landscape layout appears at full size, arranged its own way, instead of the upright one squeezed flat. Set each one up separately.

    Wallpaper and themes

    Wallpaper can be Aero's own, the phone's (live ones too, with parallax and dim) or a picture.

    Six themes in five styles, a colour mixer, and importable themes and icon packs. Match Android's colours needs a one-time grant from a computer.

    BE-Aero AI

    The phone's own assistant, on your server or an online provider. Conversations in tabs, attachments, personas, memory, voice in and out and a hands-free live voice mode.

    Summon it over any app: as the phone's digital assistant, from a Quick Settings tile, or by swiping down on the home screen. It can look at the screen when the question is about it.

    Abilities and approvals

    Each ability is switched on separately:

    • Phone actions: alarms, timers, calendar events, calls and messages made ready, directions, flashlight, volume.
    • Personal data: contacts, calendar and notifications, read only.
    • Files, with a work folder of its own that syncs to the File Pool.
    • Screen control: it operates other apps for you. This needs Android's accessibility permission.
    • Scheduled tasks.

    Looking things up never asks. The first action of a kind in a conversation shows Allow or Not now. Calls, texts and emails are prepared, and you press Send.

    BE-Aero Files

    This phone, your computers and relay storage, in list, tiles or tree. Sort, cut, copy, move and rename. Transfer jobs pause and resume. It installs APKs, and Ask AI works on a file.

    The phone backs the folders you choose up into the File Pool.

    Across the three apps

    • The media widget controls this phone or any connected PC, including volume.
    • Notifications and clipboard go to and from your computers, per device.
    • The VPN comes up by itself away from home and stays down on the home network. Home addresses are never dialled from mobile data or an unknown Wi-Fi without the VPN.
    • Updates are manual: install the newer APK.

    Build on it

    Two ways to put your own content on the desktop. The full reference is docs/SDK.md in the repository.

    Plugin widgets

    A folder with a manifest and an HTML page. Settings > Extensions > Open plugins folder takes you to the right place, then Reload picks it up.

    // aero-widget.json
{
  "id": "hello",
  "name": "Hello",
  "entry": "index.html",
  "height": 140,
  "permissions": ["telemetry", "theme"]
}
    <!-- index.html: aero-sdk.js is served by BE-Aero, do not copy it in -->
<div id="cpu">--</div>
<script src="aero-sdk.js"></script>
<script>
  (async () => {
    await aero.ready();
    await aero.useHostTheme();
    aero.telemetry.subscribe((t) => {
      document.getElementById('cpu').textContent = Math.round(t.cpu) + '%';
    });
  })();
</script>

    Plugins run sandboxed and reach BE-Aero only through the SDK. Your manifest requests a permission and the user grants it the first time you use it: telemetry, storage, theme, open-external, notifications.

    App panes: the local API

    Let a program you already run push a live status pane (title, lines, metrics, a progress bar, links) from any language. Turn on Settings > Extensions > Let local apps push widget panes. BE-Aero then listens on 127.0.0.1:8787, this machine only.

    Each program pairs once. You approve a dialog naming it, and it gets its own token, tied on Windows to that program's executable.

    # after pairing: create or replace a pane called "build"
curl -X PUT http://127.0.0.1:8787/v1/panes/build \
  -H "Authorization: Bearer $APP_TOKEN" -H "Content-Type: application/json" \
  -d '{"title":"Build","progress":70,"lines":["Compiling…"]}'
    StatusMeaning
    401Unknown or revoked token. Discard it and pair again.
    403Capability blocked, pairing declined, or the token is being used from a different program
    404Unknown endpoint, or a pane that is not yours
    413Body over 256 KB
    429A pairing prompt is already open, or this name was declined recently

    Limits: 8 panes per app, 24 overall. Panes are cleared when BE-Aero restarts.

    Troubleshooting

    Use the search box at the top to narrow these down.

    The Windows installer does nothing

    It is waiting for administrator permission. Look for the Windows prompt behind your other windows, or click the flashing shield on the taskbar.

    Windows says the app is unrecognised

    SmartScreen warns because the builds are not code-signed yet. Choose More info, then Run anyway. You can check the file against SHA256SUMS.txt on the release first.

    The search hotkey does not open search

    Another app owns it. The search bar shows which hotkey BE-Aero fell back to. Set your own in Settings > Search & general.

    An app or file is missing from search

    The index rebuilds every 30 minutes. Type aero:reindex, or use Rebuild search index in the tray.

    GNOME shows no tray icon

    Stock GNOME has no system tray. Use the toolbar's menu button, or install the AppIndicator extension.

    The Linux dock shows no windows or titles

    On GNOME, enable the helper with gnome-extensions enable be-aero-dock@be-ai-research, then log out and back in. On X11, install wmctrl and xprop. Settings shows which window source is active.

    Now Playing is empty on Linux

    Install playerctl. Volume uses wpctl or pactl.

    Something is off on my Linux desktop

    Run be-aero-desktop --doctor. It prints the session type, display map and a capability report to paste into a bug report.

    The assistant is silent for a long time

    A local model may be loading, or the server is busy with another model. After 45 seconds the status line says why. If another model is holding the server, the chat offers Unload and continue. Stop is always safe.

    The assistant stopped part-way through a job

    It reached the tool-step limit for one message and answered from what it had. Raise the limit in Settings > AI assistant, or ask it to continue.

    A local model ignores tools

    Some models have no reliable native tool support. BE-Aero switches to text tool calls automatically. You can force either mode in Settings > AI assistant > Tool call format.

    My API key was refused

    Saving a key checks it by listing the provider's models. A refused key says so plainly. Use Get a key to open the provider's key page and paste a fresh one.

    The pairing code does not work

    A code lasts 5 minutes and 5 tries. Show a new one. If the two devices cannot see each other, use Pair by address and check that TCP 41801 (or 41811 for a relay) is not blocked by a firewall.

    A device shows offline after my router restarted

    Its address changed. Devices on the same network find each other again. Otherwise set the new one in Settings > Devices > Address…

    The relay's VPN says standby

    The hub needs root once. Run sudo be-aero-relay tunnel on the relay. be-aero-relay status says why it is waiting.

    I cannot reach my relay away from home

    Forward TCP 41811 on your router to the relay machine, and UDP 51820 for the VPN hub.

    Two devices changed the same file

    Nothing is lost. The File Pool keeps the other version beside it as a conflict copy. Relay Shared storage keeps a copy named with the device and date.

    A feature on this site is not in my install

    The public downloads serve Desktop 1.2.9 and Relay 1.0.2. The Android suite, realtime sync, the VPN hub, WebGPU and the network tile arrive with 1.3.0, which is built and not yet published.

    Realtime sync will not start on my phone away from home

    The phone needs a direct connection or the VPN for realtime sync and cross-device tools. The relay mailbox for offline delivery is not on Android yet. Turn on the VPN in the phone's settings.

    Is there a macOS or iOS version?

    No. BE-Aero runs on Windows 10 and 11, Linux on X11 or XWayland, and Android 12 and later.

    Does it work on Wayland?

    Not natively. On a Wayland desktop BE-Aero runs through XWayland. On GNOME, enable the dock helper so the dock can see your windows.

    WebGPU does nothing in a web frame

    Check the WebGPU setting: Automatic, On or Off. On Linux it is opt-in and experimental. On a machine with two graphics cards, try the frame's Fast GPU option.

    A web widget shows a certificate warning

    The page uses a self-signed certificate. Check the fingerprint shown and choose Proceed to trust that exact certificate for that address. If it ever changes, the widget blocks again.

    A widget went off-screen or the layout is a mess

    Use Reset widget sizes & positions in Settings or the tray. Docked and free-form layouts are stored separately.

    Hibernate is greyed out

    Windows has hibernation turned off. The power menu shows how to turn it on.

    My local app gets 403 from the API

    Either you blocked that capability, or the token is being used from a different program than the one that paired. On Windows a token is tied to the executable, so an updated or moved unsigned program must pair again.

    Nothing in this guide matches that. Try a shorter word, or open an issue on GitHub.
